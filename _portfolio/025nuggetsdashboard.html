This project is an analytics dashboard for the Denver Nuggets that scrapes social media threads, analyzes fan sentiment using Gemini, and visualizes the data against boxscore performance to track season trends.

Use the embedded dashboard below, or the standalone site, to select specific games and players to view sentiment breakdowns and explore the correlation between player performance stats and fan sentiment.

Live Dashboard Demo

Technical Architecture

  • Frontend: React, Vite, TailwindCSS, and Recharts for high-performance data visualization.
  • API Layer: AWS AppSync (GraphQL) for real-time data fetching and subscription capabilities.
  • Database: AWS DynamoDB designed with single-table architecture for efficient querying of time-series data.
  • Backend Processing: Automated Python scripts to scrape Reddit and call gemini API for one-shot sentiment analysis.
