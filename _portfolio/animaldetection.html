--- title: "Animal Detection with Transformers" excerpt: "Bounding box object detection of animal heads from Oxford-IIIT Pet dataset using encoder-decoder transformer model built from scratch.

" collection: Portfolio order: 5 --- Full code repository available on Github.

Wrote and trained an encoder-decoder transformer model from scratch in PyTorch for bounding box object detection of animal heads from the Oxford-IIIT Pet dataset.

With only 11M parameters and 100 epochs of training, the model successfully identifies the animal and creates an accurate bounding box. There is, however, room for improvement which could be achieved with a larger model and longer training.
