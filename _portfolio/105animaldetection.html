" collection: Portfolio --- Full code repository available on Github.

Wrote and trained an encoder-decoder transformer model from scratch in PyTorch for bounding box object detection of animal heads from the Oxford-IIIT Pet.

With only 11M parameters and 100 epochs of training, the model successfully detects test examples. There is, however, room for improvement which could be achieved with a larger model and hyperparameter tuning.
