My most recent project is a <a href="http://florianfrick.github.io/portfolio/025nuggetsdashboard/">Sentiment & Performance Dashboard</a> for the Denver Nuggets NBA team. I built an automatic pipeline to scrape Reddit threads, perform one-shot sentiment analysis using Gemini’s Gemma 3 27B model, and make API requests for real-time updates of player performance.
