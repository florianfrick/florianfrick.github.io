I'm a newly graduated software developer with a <strong>Masters in Computer Science</strong> from the University of Colorado, Boulder, where I specialized in artificial intelligence and graduated with a <strong>3.94 GPA</strong>. As of November 2025, I am an <strong>AWS Certified Cloud Practitioner</strong>.

<br><br>
My most recent project is a <a href="http://florianfrick.github.io/portfolio/nuggetsdashboard/">Sentiment & Performance Dashboard</a> for the Denver Nuggets NBA team. I built an automatic pipeline to scrape Reddit threads, perform sentiment analysis using Gemini models, and upload results to a cloud database alongside player performance stats. The frontend visualizes the data and has a built in AI chat feature to answer complex user queries by referencing the actual data using an agentic RAG system.
<br><br>
My previous projects focus on solving robotics, data science, and natural language processing problems, including imitation learning for robotic manipulation, winning an autonomous robot competition, automatic sea ice mapping, and news summarization.
See my <a href="https://florianfrick.github.io/portfolio/">portfolio</a> for more details.
